# FaithCast downloads

Installers for **FaithCast**, worship presentation software for churches. Get the latest version from [Releases](https://github.com/narteychris25-lab/faithcast-releases/releases/latest).

| File | For |
|---|---|
| `FaithCast-Setup-<version>.exe` | Windows 10/11 (64-bit) |
| `FaithCast-<version>-arm64.dmg` | Mac with Apple silicon (M1 and newer) |
| `FaithCast-<version>-x64.dmg` | Mac with an Intel processor |

The installers aren't code-signed yet:

- **Windows:** if you see "Windows protected your PC", click **More info → Run anyway**.
- **Mac:** after the first open is blocked, go to **System Settings → Privacy & Security** and click **Open Anyway**.
